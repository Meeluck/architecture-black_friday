# pymongo-api

## Как запустить

Переходим в директорию `sharding-repl-cache` и выполняем команды ниже

### **Запуск**

`docker compose up -d`

### Авто настройка

1. Повышаем привилегии для скрипта

```bash
chmod +x mongo-init_task4.sh
```

2. Запускаем скрипт

```bash
./mongo-init_task4.sh 
```
